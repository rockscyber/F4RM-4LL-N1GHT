Local Game Automation
A lightweight Windows 11 automation tool that runs locally using Python, PyAutoGUI, and Pynput.
What it does
- Clicks the Play Again button every 1 minute
- Presses W every random 10–15 seconds
- Stops immediately with ESC
- Runs from PowerShell
- Does not use cloud services, APIs, accounts, or external servers
Requirements
- Windows 11
- Python 3.10 or newer
- PyAutoGUI
- Pynput
Run *py terminal_automation.py* in terminal to run the script
Note that when you enter start the targeted game should be behind the cmd so when you hit enter the cmd disapears and the game start farming, do not touch your keyboard or mouse.
